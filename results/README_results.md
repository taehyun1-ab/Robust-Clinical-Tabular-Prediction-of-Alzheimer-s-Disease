# Results Directory

This directory contains summary-level outputs generated by the experiments in this repository.

## Directory Structure

```text
results/
├── README_results.md
├── full_feature_results.csv
├── full_feature_fold_results.csv
├── random_one_feature_results.csv
├── random_two_feature_results.csv
├── random_masking_summary.csv
├── masking_probability_results.csv
├── single_feature_ablation_results.csv
└── figures/
```

Some files and subdirectories are generated locally after running the experiment scripts and may not be included in version control.

## Main Result Files

### Complete-Input Results

```text
results/full_feature_results.csv
```

This file contains the mean and standard deviation of model performance under complete-input conditions across the five cross-validation folds.

The evaluated models are:

- Random Forest
- XGBoost
- Multilayer Perceptron
- Standard FT-Transformer
- Robust FT-Transformer

The evaluated classification tasks are:

- AD vs. CN
- AD vs. MCI
- MCI vs. CN

The reported metrics include:

- Accuracy
- Precision
- Sensitivity
- F1-score
- AUROC

### Fold-Wise Complete-Input Results

```text
results/full_feature_fold_results.csv
```

This file contains fold-wise complete-input performance results.

Fold-wise outputs are used to calculate the reported mean and standard deviation across five-fold cross-validation.

### Random One-Feature Masking Results

```text
results/random_one_feature_results.csv
```

This file contains results obtained when one clinical feature is randomly masked for each test subject during inference.

The masking procedure is repeated 100 times using different subject-specific masking patterns.

### Random Two-Feature Masking Results

```text
results/random_two_feature_results.csv
```

This file contains results obtained when two clinical features are randomly masked for each test subject during inference.

The masking procedure is repeated 100 times using different subject-specific masking patterns.

### Random Masking Summary

```text
results/random_masking_summary.csv
```

This file summarizes performance under one-feature and two-feature random masking conditions.

The summary includes complete-input performance, masked-input performance, and the reduction in AUROC.

The AUROC degradation is calculated as:

```text
Delta AUROC = Complete-input AUROC - Masked-input AUROC
```

A lower Delta AUROC indicates greater robustness to missing clinical features.

A positive value indicates performance degradation under masking, whereas a negative value indicates a slight improvement relative to complete-input evaluation.

### Masking-Probability Analysis

```text
results/masking_probability_results.csv
```

This file contains results for robust FT-Transformer models trained using different feature-token masking probabilities.

The evaluated masking probabilities are:

```text
p = 0.1
p = 0.2
p = 0.3
```

The masking probability used in the main experiments is `p = 0.2`.

### Single-Feature Ablation Results

```text
results/single_feature_ablation_results.csv
```

This file contains the results of masking one clinical feature at a time during inference.

For each feature, the reduction in AUROC relative to complete-input evaluation is reported.

The evaluated features are:

- AGE
- CDRSB
- FAQTOTAL
- MMSCORE
- BMI
- PULSE
- GENDER
- APOE4

## Figures

The `results/figures/` directory may contain figures generated for the manuscript and supplementary analyses.

Expected figure files include:

```text
results/figures/model_architecture.png
results/figures/shap_AD_vs_CN.png
results/figures/shap_AD_vs_MCI.png
results/figures/shap_MCI_vs_CN.png
results/figures/attention_heatmaps.png
```

The SHAP figures contain pooled out-of-fold SHAP values from the held-out test folds of five-fold cross-validation.

The attention heatmaps contain mean CLS-to-feature attention weights averaged across attention heads, test subjects, and cross-validation folds.

## Locally Generated Directories

The following directories may be generated locally when running the code:

```text
results/checkpoints/
results/fold_results/
results/predictions/
results/shap_values/
results/attention_weights/
results/figures/
```

These directories may contain large files or participant-level outputs and are therefore excluded from version control when appropriate.

## Files Not Included in the Repository

The following files are not publicly distributed:

- raw ADNI data
- processed participant-level datasets
- participant identifiers
- subject-level predictions
- subject-level SHAP values
- raw attention weights linked to individual subjects
- model checkpoints
- restricted data-derived outputs

These files are excluded to comply with the ADNI data-use agreement and to avoid redistribution of participant-level information.

## Publicly Shareable Results

The repository may include summary-level outputs that do not contain participant identifiers or subject-level records.

Examples include:

- mean and standard deviation across cross-validation folds
- task-level performance summaries
- masking-probability comparisons
- feature-level ablation summaries
- aggregated SHAP figures
- aggregated attention heatmaps

## Reproducibility Notes

The main experiments use:

- stratified five-fold cross-validation
- fixed random seeds
- training-only preprocessing
- complete-input evaluation
- one-feature random masking
- two-feature random masking
- 100 repetitions for random masking evaluation

All reported summary results should be generated from the corresponding experiment scripts in the `code/` directory.

Exact output file names may be adjusted to match the final implementation. The file names documented here should remain consistent with the paths described in the main `README.md`.
